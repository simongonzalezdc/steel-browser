# Pull and run the Docker image

The best way to build live web agents and browser automation tools.

## Quick start

```bash
# Pull and run the Docker image
docker run -p 3000:3000 -p 9223:9223 ghcr.io/steel-dev/steel-browser
```

```bash
docker compose up
```
